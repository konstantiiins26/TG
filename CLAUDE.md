# CLAUDE.md — контекст проекта

Память проекта для будущих сессий. Сессия в чате не переживает перезапуск
контейнера; этот файл переживает.

## Что это

Снайпер NFT-подарков Telegram в сети TON. Ищет недооценённые лоты, считает
экономику перепродажи, проверяет решение через Claude и соблюдает риск-лимиты.

- `gift_sniper.py` — всё приложение одним файлом (так попросил пользователь)
- `test_gift_sniper.py` — тесты, сети не требуют. **Запускать перед каждым коммитом.**
- `SETUP.md` — что пользователь должен предоставить; главный документ для него
- `deploy/` — systemd-юнит и Dockerfile

## Принятые решения (не откатывать без причины)

**Экономика.** Комиссия и роялти берутся с цены ПРОДАЖИ, не покупки. Формула
из исходного ТЗ (`(Floor−Buy) − Buy×5% − gas`) систематически завышала прибыль
и была исправлена намеренно.

**Floor.** Считается как 5-й перцентиль по выборке в несколько страниц, а не
`min()` по первой. У API нет сортировки по цене; `min()` по 20 лотам из 50 000
— это не floor. Малая выборка → торговля пропускается.

**Whitelist по адресу, не по имени.** Скам-коллекции копируют имя и картинки.
Адреса нормализуются (raw ↔ EQ.../UQ..., CRC16) перед сравнением.

**`PREMIUM_MULT = 1.0` по умолчанию.** Красота номера и редкость НЕ влияют на
решение, пока пользователь не откалибрует премию по своей записи рынка. Любое
значение выше 1.0 увеличивает расчётную прибыль — это направление, в котором
теряют деньги.

**Проверки «переплата над floor» нет намеренно.** Она была недостижима:
прибыль возможна только ниже ~0.87×floor. Расчёт прибыли её поглощает.

**`evaluate_trade()` — единственный источник истины.** Бэктест обязан вызывать
ЕЁ ЖЕ. Бэктест по копии логики не проверяет ничего.

**Детерминированный фильтр идёт ДО Claude.** ИИ не может отменить отказ, поэтому
спрашивать его про отбракованный лот — платить за ответ ни о чём.

**`execute_blockchain_buy()` никогда не возвращает True, не совершив сделку.**
Иначе в БД появится позиция, которой нет, и учёт PnL станет фикцией.

## Что НЕ сделано и почему

**Реальная подпись транзакций.** `REAL_EXECUTOR_AVAILABLE = False`, живой режим
заблокирован в `preflight_checks()`. Установка `tonutils`/`pytoniq` в среде
разработки блокируется политикой, а писать код траты денег по памяти нельзя.
Нужна либо установка библиотеки, либо вывод её API от пользователя.

**Форма ответов TonAPI/Getgems не верифицирована** — сеть к `tonapi.io` и
`api.getgems.io` в среде разработки закрыта. Парсинг может потребовать правок
по логам первого реального запуска.

## Правила работы с этим репозиторием

- Секреты только через окружение/файл с правами 0600. Ключ не логировать,
  не писать в БД, не слать в уведомлениях.
- Перед коммитом: `python test_gift_sniper.py` — должно быть «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ».
- Не ослаблять ворота живого режима «чтобы заработало».
- Изменения, увеличивающие расчётную прибыль, требуют обоснования данными,
  а не рассуждением.
