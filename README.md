# Telegram Gifts NFT Sniper 🎁🤖

Автоматический снайпер и ИИ-аналитик рынка NFT-подарков Telegram (сеть TON).

Бот в реальном времени мониторит лоты на рынке, отдаёт данные "ИИ-мозгу"
(Claude API), который считает чистую прибыль и отсекает переплату за хайп,
и при вердикте `BUY` вызывает **безопасную заглушку** покупки (реальная
подпись транзакции не выполняется до ваших тестов).

## Как это работает

1. **Сбор данных** — TonAPI.io (`/v2/nfts/collections/{address}/items`),
   с фолбэком на Getgems GraphQL. Собираются: адрес подарка, коллекция,
   номер минта, цена продажи (нанотоны → TON) и Floor Price коллекции.
2. **ИИ-мозг** — Claude считает
   `NET_PROFIT = (Floor − Buy) − (Buy × 5%) − 0.15 TON` и `ROI`, отсекает
   некрасивые минты вне топ-100 как переплату, и возвращает строгий JSON:
   `{ ACTION, ROI_PERCENT, NET_PROFIT_TON, REASON }`.
3. **Цикл** — бесконечный `while True` c задержкой 10–15 сек и подробным
   логом каждой проверки и вердикта.
4. **Покупка** — заглушка `execute_blockchain_buy()` симулирует успех
   (`[SUCCESS] ...`) вместо реальной транзакции.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите свои ключи
export ANTHROPIC_API_KEY="sk-ant-..."
export TARGET_COLLECTION="EQ...адрес коллекции..."
python gift_sniper.py
```

Все параметры настраиваются через переменные окружения или блок `CONFIG`
в начале `gift_sniper.py`.

## ⚠️ Безопасность

- `DRY_RUN=1` (по умолчанию) — покупка только симулируется, средства в
  безопасности.
- Секреты (`ANTHROPIC_API_KEY`, `TONAPI_KEY`, `WALLET_PRIVATE_KEY`) — только
  через окружение. `.env` уже в `.gitignore` — **не коммитьте реальные ключи**.
- Реальная подпись транзакции намеренно не реализована. Подключайте её
  (например, через `tonutils` / `pytoniq`) только после полного тестирования
  и на свой риск.

## Примечание про модель

В ТЗ упоминался `claude-3-5-sonnet` — это устаревший ID. По умолчанию
используется актуальная быстрая и недорогая модель `claude-sonnet-5`
(идеально для частого опроса). Переопределяется переменной `CLAUDE_MODEL`.
